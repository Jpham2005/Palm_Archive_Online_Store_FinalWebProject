# Palm Archive Online Store

## Project Overview
Palm Archive Online Store is an ASP.NET Core MVC e-commerce website for luxury fashion products.

## Features

- Browse fashion products
- Search products by name, brand, and category
- View product details
- Add products to shopping cart
- Remove products from cart
- Contact seller through Instagram
- Admin product management
- Database integration using Entity Framework Core

## Technologies

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- Razor Views
- HTML/CSS/JavaScript

## How to Run

1. Clone the repository
2. Open `PalmArchiveBest.slnx` in Visual Studio
3. Build the solution
4. Run the project
